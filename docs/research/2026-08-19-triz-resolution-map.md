# TRIZ-style resolution map

| Contradiction | Separation/resolution principle |
| --- | --- |
| more autonomy vs fixed authority | separate coordination duration from effect authorization |
| portability vs stronger local security | portable request schema + kernel-owned enforcement extensions |
| rich agent specialization vs context explosion | subagent-local context + structured result handoff |
| Android simplicity vs deep observability | progressive disclosure + semantic state components |
| adaptive learning vs reproducibility | versioned configuration tuples + controlled evaluation/promotion |
| fast resume vs uncertain external effects | checkpoint coordination + effect-specific reconciliation |

These are design heuristics; implementation still requires tests/evidence.
