# Academic evidence direction

When a milestone depends on an algorithmic claim (retrieval, agent routing, planning, memory, evaluation, optimization), search for recent peer-reviewed/preprint work with released code or reproducible outcomes. Prefer mechanisms that can be evaluated against AutoDev's own historical/fault-injection corpus.

A paper's benchmark gain is a hypothesis for AutoDev, not implementation proof. Record citation/code version, reproduced behavior where feasible, and local evaluation results before promoting the mechanism.
