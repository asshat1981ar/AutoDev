# Harness/plugin supply-chain direction

Later production hardening should bind each externally sourced harness asset to source/version/integrity metadata and preserve the resolved artifact identity in run provenance.

Activation should distinguish discovery, installation/materialization, validation, and capability authorization. A verified digest proves artifact identity, not safety or permission. Trust metadata informs policy and diagnostics but never bypasses capability evaluation.

The implementation should investigate signing/transparency mechanisms only after the portable asset schema is stable enough to identify what exactly is signed.
