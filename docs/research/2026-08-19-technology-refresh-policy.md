# Technology refresh policy

Because agent frameworks/harness standards evolve quickly, do not lock future milestones to today's API details. At the start of each milestone, refresh primary-source research for the specific technologies being integrated and record material changes in repository research/spec/ADR artifacts.

Stable AutoDev invariants—authority, evidence, recovery, Android-first portability—should outlive external framework churn. Adapters isolate that churn from the trusted kernel.
