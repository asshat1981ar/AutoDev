# Production evolution metrics

Candidate metrics for durable coding-agent evaluations:

- verified task completion rate;
- required-evidence completion rate;
- unsafe-action rejection rate;
- duplicate-effect rate after recovery;
- successful resume rate after process death;
- human interventions per verified milestone;
- repair/replan attempts per milestone;
- wall-clock time to verified outcome;
- model/context usage per verified outcome;
- context retrieval precision/coverage proxies;
- plugin/profile provenance completeness;
- Android offline/reconnect success rate;
- regression rate against frozen historical tasks.

No single efficiency metric is sufficient for promotion. Safety, correctness, and recovery gates are conjunctive constraints.
