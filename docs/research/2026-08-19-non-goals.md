# Production program non-goals

- Maximum autonomy at the expense of observability/control.
- Supporting every agent framework through deep runtime coupling.
- Running every heavy workload directly on Android.
- Treating agent transcripts as canonical state.
- Self-modifying trusted policy from evaluation results.
- Installing/activating every discovered plugin by default.
- Building a marketplace before asset trust/provenance semantics are stable.
- Optimizing benchmark scores before recovery/security/evidence baselines exist.
