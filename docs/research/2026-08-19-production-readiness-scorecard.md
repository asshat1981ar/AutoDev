# Production readiness scorecard

Future release qualification should report each dimension as `green`, `conditional`, or `red` with evidence references:

| Dimension | Status | Evidence |
| --- | --- | --- |
| Trusted authority boundary | pending | |
| Durable recovery/reconciliation | pending | |
| Independent verification | pending | |
| Plugin/harness supply-chain trust | pending | |
| Android install/startup/runtime | pending | |
| Offline/reconnect behavior | pending | |
| Multiplatform semantic parity | pending | |
| Evaluation/regression baseline | pending | |
| Performance/resource budgets | pending | |
| Accessibility/usability | pending | |
| Onboarding/diagnostics | pending | |
| Reproducible release pipeline | pending | |

Any red authority, recovery, verification, or release-integrity dimension blocks production release.
