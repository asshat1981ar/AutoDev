# Feature branch scope

`feat/execplan-control-plane` contains the first production-evolution implementation slice plus durable research/planning artifacts that constrain later milestones.

Production code scope is intentionally limited to the ExecPlan domain/export and focused contract verification. Harness Protocol adapters, plugin loaders, persistent storage, Android UI, adaptive routing, and Simulation/Eval Lab code remain out of scope until their milestone entry criteria are satisfied.
