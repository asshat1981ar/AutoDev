# Autonomous development stop conditions

A running milestone proceeds without routine human prompts. Stop/escalate when:

- an irreversible/destructive operation needs approval;
- a security-sensitive action requires trusted authorization;
- merge/publish/shared-branch side effect requires explicit consent under workflow norms;
- repository/spec evidence is so contradictory that every implementation path would be a guess;
- product requirements require a genuinely new major direction not covered by the approved architecture.

Ordinary implementation ambiguity is resolved through repository evidence, small reversible choices, and recorded rulings.
