# Evaluator asset direction

An evaluator describes how candidate behavior is measured; it is not itself promotion authority. Evaluator assets should identify task corpus/version, verifier recipe, metrics, protected surfaces, hidden checks where applicable, and reproducibility metadata.

Harness/profile/toolset experiments must retain the exact evaluator identity used. Promotion decisions should consume evaluator evidence through a separate policy so a candidate cannot choose a weak evaluator and promote itself.
