# Evidence-backed configuration promotion policy sketch

A learned toolset, agent assignment, context strategy, or harness profile may become a recommended candidate when it improves held-out verified outcomes. Becoming a default requires stronger evidence:

- no authority-boundary regression;
- no required-evidence regression;
- no material recovery regression;
- statistically/practically meaningful improvement across more than one task family;
- reproducible configuration/provenance;
- rollback path to the prior default.

The learning system proposes promotion. A separate promotion policy decides. Evaluation results never mutate trusted policy directly.
