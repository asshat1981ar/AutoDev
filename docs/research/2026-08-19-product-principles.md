# Product principles

- Show outcomes and required intervention before internal agent chatter.
- Make evidence as visible as generated code.
- Preserve user control through exact scoped approvals, cancellation, and reprioritization.
- Treat interruption/offline operation as normal product states.
- Keep advanced harness configuration inspectable but progressively disclosed.
- Prefer useful degraded operation over brittle all-or-nothing platform assumptions.
- Explain failure from typed state/evidence, not opaque agent prose.
