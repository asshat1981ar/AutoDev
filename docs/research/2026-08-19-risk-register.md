# Federated Harness Kernel risk register

| Risk | Early detection | Mitigation direction |
| --- | --- | --- |
| Imported plugin expands authority | adversarial capability tests | all imported permissions become policy requests |
| Resume duplicates uncertain effect | fault-injection restart tests | reconciliation-required state |
| Harness profile silently removes security layer | profile conformance tests | kernel requirements live outside profile-removable surface |
| Adaptive routing overfits historical tasks | held-out/frozen evaluations | promotion policy + regression thresholds |
| Android UI hides approval scope | usability/approval comprehension tests | exact capability/effect summaries + progressive detail |
| Portable schema forks ecosystem standard | schema-gap review | Harness Protocol import/export first |
| Context growth breaks long runs | context budget telemetry | subagent isolation + summarization + deterministic retrieval |
| Plugin supply-chain compromise | integrity/provenance checks | trust classes, digest/signature policy, fail-closed activation |
