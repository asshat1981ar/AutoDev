# Production evolution definition of done

The long-running program is not done when all planned files exist. It is done when a fresh user can install AutoDev, connect/import a project, start a durable development objective from Android, observe and intervene in a multi-agent run, survive interruption/offline periods, review exact requested capabilities and diffs, and receive independently verified completion evidence.

The same durable objective must remain inspectable/resumable through supported companion platforms without changing the trusted execution boundary. External harness assets should be portable where standards permit, provenance should be inspectable, unsafe/unsupported capabilities should fail closed, and release/evaluation baselines should be reproducible.
