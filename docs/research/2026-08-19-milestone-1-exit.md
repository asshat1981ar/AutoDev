# Milestone 1 exit criteria — ExecPlan Control Plane

Milestone 1 exits only when:

- repository PLANS.md contract is present/enforced;
- typed authority-free plan state compiles and serializes;
- invalid identity/budgets/milestones fail closed;
- finite replanning and reconciliation-before-resume are tested;
- checkpoint coordination state round-trips;
- ADR/docs accurately describe the boundary;
- focused CI is green;
- existing repository CI is green or any unrelated pre-existing failure is clearly evidenced;
- final review has no unresolved load-bearing finding.
