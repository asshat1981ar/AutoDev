# Minimum viable production path

To reach a credible production beta without implementing every research idea:

1. Durable ExecPlan/task/envelope persistence and crash recovery.
2. Small HarnessAsset/Profile system with provenance and at least one portable import path.
3. Safe local/remote execution with exact approvals and evidence gating.
4. Android run dashboard, review/approval, evidence, recovery/offline flow.
5. Reproducible build/install pipeline plus fault/security regression suite.
6. Historical evaluation baseline and production-readiness scorecard.

Adaptive self-optimization and broad plugin marketplace functionality can follow after this path is reliable.
