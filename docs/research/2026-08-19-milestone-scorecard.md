# Production evolution milestone scorecard

Every milestone should report these dimensions before promotion:

- Verified functional completion.
- Authority-boundary preservation.
- Recovery/failure behavior.
- Determinism/reproducibility.
- Context/resource efficiency.
- Android/Termux compatibility impact.
- Multiplatform contract impact.
- Supply-chain/provenance impact.
- Accessibility/usability impact when user-facing.
- Regression evidence against prior baseline.

A milestone with improved capability but weakened authority, verification, or recovery does not pass.
