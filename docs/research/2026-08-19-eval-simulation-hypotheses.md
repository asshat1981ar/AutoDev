# Eval/simulation hypotheses for Federated Harness Kernel

These hypotheses become executable experiments in the Simulation/Eval Lab milestone.

1. Declarative provider/model harness profiles improve verified completion rate over a single universal harness without increasing unsafe-action acceptance.
2. Subagent context isolation reduces main-agent context growth and improves long-horizon recovery.
3. Harness Protocol import/export can improve ecosystem portability without changing ForgeCore authorization outcomes.
4. Explicit interrupted-effect reconciliation reduces duplicate/replayed mutations after process failure.
5. Evidence-backed toolset/profile selection outperforms static routing on historical AutoDev tasks while remaining within bounded retry/replan budgets.

Promotion criteria must include correctness and safety gates; latency/token savings alone cannot promote a configuration.
