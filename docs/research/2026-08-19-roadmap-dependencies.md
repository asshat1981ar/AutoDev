# Production evolution dependency map

```text
ExecPlan control plane
  -> durable orchestration
  -> Android run/recovery UX

Harness schema-gap research
  -> Harness Asset Protocol
     -> external adapters
     -> declarative harness profiles
     -> plugin supply-chain hardening

Context intelligence
  -> durable orchestration efficiency
  -> adaptive routing

Self-evaluation factory
  -> Simulation/Eval Lab
     -> adaptive routing promotion policy

Durable orchestration + Harness Assets + Android UX
  -> multiplatform parity
     -> production release qualification
```

The dependency graph intentionally prevents adaptive self-configuration from preceding trustworthy evaluation and prevents Android UI from becoming the source of execution authority.
