# Production evolution contradiction register

## Autonomy vs authority

Increase the duration and independence of agentic work without increasing untrusted authority. Resolution direction: richer durable coordination + stronger evidence/recovery, while ForgeCore authority remains fixed.

## Portability vs security semantics

Import more external harness formats without accepting weaker permission models. Resolution direction: lossless import where possible; translate permissions into requests; fail closed on unsupported trust semantics.

## Android simplicity vs system depth

Expose deep multi-agent orchestration on a small mobile surface without creating an unusable control panel. Resolution direction: progressive disclosure centered on goal → progress → evidence → intervention, with advanced provenance/debug surfaces secondary.

## Adaptation vs reproducibility

Learn better toolsets/profiles while keeping runs explainable and comparable. Resolution direction: immutable evidence-backed experiment records, frozen evaluation tasks, bounded promotions, and reversible defaults.

## Long-running execution vs stale external state

Resume after interruption without blindly replaying effects. Resolution direction: checkpoint coordination state but reconcile uncertain external effects before retry.
