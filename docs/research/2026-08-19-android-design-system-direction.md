# Android design-system direction

Build reusable Compose components around semantic agentic states rather than one-off dashboard widgets: RunStatus, MilestoneProgress, ApprovalCard, EvidenceCheck, DiffSummary, RecoveryNotice, AgentActivity, HarnessAssetBadge, and DiagnosticAction.

Components should encode accessibility semantics and responsive behavior from the start. Visual polish follows semantic correctness; state meaning must remain consistent across Android and companion clients.
