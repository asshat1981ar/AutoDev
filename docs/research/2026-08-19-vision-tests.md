# End-vision acceptance scenarios

1. Start a multi-hour refactor from Android; phone process dies; run resumes without duplicated mutation and finishes with independent evidence.
2. Import a portable harness with skills/plugins/MCP permissions; AutoDev preserves provenance but denies an effect not allowed by ForgeCore policy.
3. Switch model/provider; declarative profile changes the harness surface while security/evidence behavior remains invariant.
4. Work offline; queue a new objective/review action; reconnect after repository state changed; AutoDev reconciles rather than blindly replaying.
5. Compare two agent/profile/toolset configurations on frozen tasks; promote the better candidate only when protected correctness/safety/recovery gates remain green.
6. Inspect the same durable run on Android and a companion client with consistent task/evidence/approval state.
