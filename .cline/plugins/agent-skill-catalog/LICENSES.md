# License and Attribution Notes

The upstream `VoltAgent/awesome-agent-skills` repository is an index of links to many external skills. Its repository license does not automatically apply to every linked skill or to every referenced source.

## Current vendoring status

This plugin currently vendors **no third-party skill bodies** from the upstream index. All active `SKILL.md` files in this plugin are original AutoDev workflow guidance.

## Source attribution

- VoltAgent awesome-agent-skills: https://github.com/VoltAgent/awesome-agent-skills

## Before vendoring an external skill

Record:

1. source URL;
2. source repository;
3. exact revision or release when possible;
4. license file and SPDX identifier when available;
5. whether copied text, adapted text, scripts, or only links are used;
6. attribution required by the source license;
7. security review result;
8. AutoDev authority classification.
